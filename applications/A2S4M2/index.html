Synthèse de Cours : Fonctions Affines $f(x) = ax + b$

1. Définition & Rôle des Coefficients

Une fonction affine associe à tout nombre $x$ : $f(x) = ax + b$.

  • $a$ : Coefficient directeur (pente). Taux de variation régulier : $$a = \frac{y_2 - y_1}{x_2 - x_1}$$
  • $b$ : Ordonnée à l'origine. C'est l'image de 0 : $f(0) = b$. Graphiquement, la droite coupe l'axe vertical au point $(0\,;\,b)$.

2. Sens de Variation

  • a > 0 Fonction strictement croissante (la droite monte).
  • a < 0 Fonction strictement décroissante (la droite descend).
  • a = 0 Fonction constante (droite horizontale $f(x)=b$).

Application à la table d'esthétique :

$V(x) = -800x + 2~400$ sur $[0\,;\,3]$.
• Pente $a = -800\text{ €/an}$ : dépréciation annuelle constante.
• Ordonnée à l'origine $b = 2~400\text{ €}$ : valeur d'achat neuve.
• Au bout de $3$ ans : $V(3) = -800(3) + 2~400 = 0\text{ €}$ (matériel totalement amorti).
