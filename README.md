# CAP Esthétique Cosmétique Parfumerie – Année 2

Portail CMA Formation Sainte-Clotilde. Code partagé : CMAFormationSC.

## Publication
Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Applications
Six dossiers complets intégrés sans modification : A2S3M1, A2S3M2, A2S3P1, A2S4M1, A2S4M2, A2S4P1. Les six cartes sont visibles immédiatement.

## Ajouter une activité
Déposer le dossier complet dans applications/CODE/index.html avec ses ressources. Ajouter un objet dans window.APPLICATIONS de applications.js avec code, annee, semaine, discipline (M ou P), activite, titre, description et lien. Séparer les objets par une virgule. Aucun changement de index.html requis.

Champ facultatif de publication : `publication: "2026-11-06T08:00:00+04:00"`. Sans ce champ, affichage immédiat. Tri par année, semaine et numéro d’activité.

Le code et la publication différée sont des barrières pédagogiques : les fichiers restent publics et les dates dépendent de l’horloge de l’appareil. Aucun compte nominatif.
